1. Rumus Dasar Kalkulus 1

Materi Fungsi f(x) Hasil Turunan f'(x) / Integral ∫
Turunan Aljabar f(x) = a · xⁿ f'(x) = a · n · xⁿ⁻¹
Turunan Trigonometri f(x) = sin(x) f'(x) = cos(x)
Integral Tentu Dasar ∫ xⁿ dx [1 / (n + 1)] xⁿ⁺¹ + C

2. Contoh Soal Pembahasan

Contoh 1: Turunan Fungsi Aljabar

Tentukan turunan pertama dari fungsi f(x) = 4x³ + 2x² - 5!

Klik untuk Lihat Pembahasan

Langkah Penyelesaian:

1. Turunan 4x³ = 4 · 3 · x³⁻¹ = 12x²

2. Turunan 2x² = 2 · 2 · x²⁻¹ = 4x

3. Turunan konstanta (-5) = 0

Hasil Akhir: f'(x) = 12x² + 4x

Contoh 2: Integral Tak Tentu

Tentukan hasil dari ∫ 6x² dx!

Klik untuk Lihat Pembahasan

Langkah Penyelesaian:

Gunakan rumus: ∫ a·xⁿ dx = [a / (n+1)] xⁿ⁺¹ + C

= [6 / (2 + 1)] x²⁺¹ + C

= (6 / 3) x³ + C

Hasil Akhir: 2x³ + C

3. Latihan Soal Mandiri

Latihan 1: Turunan Trigonometri

Carilah turunan pertama dari f(x) = 3 sin(x) + 2 cos(x)!

Cek Kunci Jawaban

Ingat: Turunan sin(x) adalah cos(x), dan turunan cos(x) adalah -sin(x).

Jawaban: f'(x) = 3 cos(x) - 2 sin(x)

Latihan 2: Integral Sederhana

Hitunglah nilai dari ∫ (3x² + 4x) dx!

Cek Kunci Jawaban

Integral 3x² = x³

Integral 4x = 2x²

Jawaban: x³ + 2x² + C
